# CCTB Next.js Starter

A coursework repository containing a Next.js App Router starter.

The checked-in home page retains the generated Next.js example. This snapshot establishes the application scaffold, rather than a completed custom product.

## Start reading

- [`src/`](src/)

## Development

Use Node.js and npm compatible with the versions recorded in the package manifest and lockfile. Each package is installed from its own directory.

From the repository root:

```sh
npm install
npm run dev
```

Additional scripts in this package: `npm run build`, `npm run lint`.
